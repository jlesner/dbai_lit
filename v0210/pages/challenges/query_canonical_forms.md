# Canonical forms for queries

> An open problem: normal forms for useful SQL fragments, so that comparing two queries' forms decides (or nearly decides) equivalence. Sound when the forms match; silent when they don't.

<p class="tags"><a class="tag" href="#/tags/prove">prove</a><a class="tag" href="#/tags/rules">rules</a><a class="tag" href="#/tags/theory">theory</a></p>

## Challenge
Find normal forms that are as canonical as possible for useful SQL fragments, so that equivalence (or "close to equivalent") can be read off by comparing forms.

## Why it matters
- **More proofs from the provers we have.** UDP, SPES and QED all normalize both queries before matching them ([UDP](#/papers/chu2018udp "Axiomatic foundations and algorithms for deciding semantic equivalences of SQL queries (2018)") §5.1–5.2, [SPES](#/papers/zhou2020spes "SPES: A Symbolic Approach to Proving Query Equivalence Under Bag Semantics (2022)") §4.2, [QED](#/papers/wang2024qed "QED: A Powerful Query Equivalence Decider for SQL (2024)") §4–5). The QED authors trace misses by UDP and SPES to normal forms that fall back on syntactic matching, e.g. `[a+b=0]` against `[a=-b]` (§1, §6.3), and WeTune's authors show an outer-join pair UDP's isomorphism test can't prove ([WeTune](#/papers/wang2022wetune "WeTune: Automatic Discovery and Verification of Query Rewrite Rules (2022)") §5.1, Fig. 5). SPES's authors trace most supported pairs it leaves unproved to missing normalization rules ([SPES](#/papers/zhou2020spes "SPES: A Symbolic Approach to Proving Query Equivalence Under Bag Semantics (2022)") §7.4), and EQUITAS's say pairs with structural differences need structural transformation rules ([EQUITAS](#/papers/zhou2019equitas "Automated verification of query equivalence using satisfiability modulo theories (2019)") §6.4). QO-Verify compares the expression sets its optimizer generates after normalization, and its authors suggest normalizing scalar expression trees to raise coverage ([QO-Verify](#/papers/narasayya2026qoverify "Leveraging Query Optimizers to Verify the Soundness of LLM-based Query Rewrites for Real-World Workloads, and More! (2026)") §2.2). In our reading, stronger forms would turn *unknown* into proofs, which is what [SQL features that verifiers don't cover](#/challenges/verifier_coverage_gaps) needs.
- **Shared work across a workload.** The GEqO authors call detecting equivalent subexpressions "the first and crucial step" for view selection, view matching and multi-query optimization ([GEqO](#/papers/haynes2024geqo "GEqO: ML-Accelerated Semantic Equivalence Detection (2023)") §1). In their account, signatures (CloudViews' Merkle-tree hashes) find only syntactically identical subexpressions, and pairwise proving is quadratic (§1). In their synthetic test, signatures find far fewer equivalences (§7.5, Fig. 13a). In our reading, a canonical form is a hash key: one pass per query, with no pairwise calls.
- **A cheap "equivalent" for grading and evaluation.** The XData grading authors use a canonical-form match as a sufficient test that a student query is correct ([Edit Based Grading of SQL Queries](#/papers/chandra2019grading "Edit Based Grading of SQL Queries (2019)") §1), because generating data for each student query is expensive (§4.7) and prior equivalence checkers don't handle many SQL features (§1). Spider's exact set match is a cruder form comparison. The test-suite authors report that it rejects equivalent predictions ([Semantic Evaluation for Text-to-SQL…](#/papers/zhong2020testsuite "Semantic Evaluation for Text-to-SQL with Distilled Test Suites (2020)") §6.2, Tab. 1) and that its looser official version accepts some wrong ones (§5.3, §7). The forms are only as good as their rules: one printed XData rule and one worked example change query results, so [Refuting faulty rewrite rules](#/challenges/faulty_rewrite_rules) applies.

**Size of the gain:** incremental, measured as the share of equivalent query pairs that a form comparison certifies without a prover call or test data. Full SQL has no computable canonical form, and fragment forms already sit inside the provers, so progress widens the fragment and cuts cost. It doesn't make anything new possible. Workload reuse may gain more, but GEqO's evidence is synthetic ([GEqO](#/papers/haynes2024geqo "GEqO: ML-Accelerated Semantic Equivalence Detection (2023)") §7). This is our estimate.

## Verifiable signal
Matching normal forms are a proof, provided every rule used is verified. Different forms are no signal at all.
