- **[UDP](#/papers/chu2018udp "Axiomatic foundations and algorithms for deciding semantic equivalences of SQL queries (2018)")**: Axiomatic foundations and algorithms for deciding semantic equivalences of SQL queries (PVLDB 11(11) 2018). U-semirings: semiring semantics with unbounded summation and duplicate elimination, implemented in a proof assistant. <span class="links">[🔎 Summary](#/papers/chu2018udp) · [PDF](https://arxiv.org/pdf/1802.02229) · [arXiv](https://arxiv.org/abs/1802.02229) · [DOI](https://doi.org/10.14778/3236187.3236200) · [Code](https://github.com/uwdb/Cosette)</span> <span class="tags"><a class="tag sub" href="#/tags/itp-sql">itp-sql</a><a class="tag sub" href="#/tags/prove-itp">prove-itp</a><a class="tag sub" href="#/tags/rules-verify">rules-verify</a></span>
