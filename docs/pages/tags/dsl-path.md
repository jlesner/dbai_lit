- **[XML Path Language (XPath) Version 1.0](#/papers/clark1999xpath "XML Path Language (XPath) Version 1.0 (1999)")** (W3C Recommendation 16 November 1999 (status updated October 2016); a standard, filed as a paper). Defines XPath 1.0, "a language for addressing parts of an XML document" made for XSLT and XPointer (abstract; §1), with a grammar in EBNF (§1), a tree data model of seven node types (§5) and a core function library every implementation must support (§1; §4). <span class="links">[🔎](#/papers/clark1999xpath "Summary") · [Paper](https://www.w3.org/TR/1999/REC-xpath-19991116)</span> <span class="tags"><a class="tag" href="#/tags/method">method</a><a class="tag sub" href="#/tags/dsl-path">dsl-path</a></span>
- **[XQuery 1.0 and XPath 2.0 Formal Semantics (Second Edition)](#/papers/draper2010semantics "XQuery 1.0 and XPath 2.0 Formal Semantics (Second Edition) (2010)")** (W3C Recommendation 2010, revised 2015 (a standard, not a paper)). W3C's formal semantics of XQuery 1.0 and XPath 2.0: each expression is rewritten ("normalized") into a smaller Core language, which gets static typing rules and dynamic evaluation rules, written as inference rules (§3.2; §4). <span class="links">[🔎](#/papers/draper2010semantics "Summary") · [Paper](http://www.w3.org/TR/2010/REC-xquery-semantics-20101214/)</span> <span class="tags"><a class="tag" href="#/tags/method">method</a><a class="tag sub" href="#/tags/dsl-path">dsl-path</a><a class="tag sub" href="#/tags/nondet-semantics">nondet-semantics</a></span>
- **[Efficient Static Analysis of XML Paths and Types](https://inria.hal.science/inria-00502789/document "Efficient Static Analysis of XML Paths and Types (2007)")** (PLDI 2007). Decides XPath emptiness, containment, overlap and coverage, with or without regular tree type constraints (DTDs and other XML schemas), by testing whether one formula over finite trees is satisfiable (abstract, PDF p. 1; §8, PDF pp. 8–9); the XPath fragment "covers all features except counting [8] and data values" (§1, PDF p. 1), though its abstract syntax (Fig. 3, PDF p. 3) has 11 of XPath 1.0's 13 axes (no attribute or namespace axis). <span class="links">[🔎](#/papers/geneves2007efficient "Summary") · [PDF](https://inria.hal.science/inria-00502789/document) · [DOI](https://doi.org/10.1145/1250734.1250773)</span> <span class="tags"><a class="tag" href="#/tags/method">method</a><a class="tag" href="#/tags/prove">prove</a><a class="tag sub" href="#/tags/dsl-path">dsl-path</a></span>
- **[XML Static Analyzer User Manual](https://arxiv.org/pdf/0812.3550 "XML Static Analyzer User Manual (2008)")** (INRIA research report RR-6726 (arXiv 2008)). User manual of a satisfiability solver for a logic of finite trees that decides XPath emptiness, containment and equivalence, optionally under a DTD, XML Schema or Relax NG type, and outputs a satisfying or counterexample XML tree (§2, Examples 1–3; §3.2 "Supported XML Types"; §4). <span class="links">[🔎](#/papers/geneves2008analyzer "Summary") · [PDF](https://arxiv.org/pdf/0812.3550) · [arXiv](https://arxiv.org/abs/0812.3550)</span> <span class="tags"><a class="tag" href="#/tags/cex">cex</a><a class="tag" href="#/tags/method">method</a><a class="tag" href="#/tags/prove">prove</a><a class="tag sub" href="#/tags/dsl-path">dsl-path</a></span>
