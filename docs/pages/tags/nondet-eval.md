# Tag <span class="tag sub big">nondet-eval</span>

A subtag of <a class="tag" href="#/tags/nondet">nondet</a>

**Handles nondeterminism when results are compared in practice**: detects or filters nondeterministic queries or features, accepts any of several correct outputs (e.g. rewritten references that return all tied rows), or separates nondeterministic parts from deterministic logic before evaluating.
