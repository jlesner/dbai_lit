# Tag <span class="tag big">labels</span>

**Benchmark ground truth**: audits that measure how often a benchmark's labels, tests or verifiers are wrong (false accepts or false rejects of the grading), and benchmarks or pipelines whose labels a check backs (proofs, certified counterexamples, executable specifications), in any domain (text-to-DSL items keep their <a class="tag" href="#/tags/nl2dsl">nl2dsl</a> subtags as well).

<!-- filter -->

## Challenges

- **[A gym of DSL tasks with answer keys made by code](#/challenges/dsl_gym)**: Task families in several DSLs (predict a program's output, write a program from examples or from English, decide whether two programs agree and show where they don't) whose answer keys come from the engine, with a size setting on two axes, and checks whose false accepts are measured.
