# Tag <span class="tag sub big">llm-assist</span>

A subtag of <a class="tag" href="#/tags/llm">llm</a>

The LLM is a **helper inside a checker, tester or tool**, and the final verdict comes from a non-LLM tool, which may rely on what the LLM produced without re-checking it: proof steps, mined or validated constraints, test databases, oracle skeletons, parse segments, running the NL question on a database.
