# Tag <span class="tag sub big">llm-gen</span>

A subtag of <a class="tag" href="#/tags/llm">llm</a>

The LLM **writes SQL or another DSL's queries**: rewrites, dialect translations and migrations, text-to-DSL, and benchmarks of that generation (an evaluation that runs LLM generators in its own experiments); rewrites that are verified afterwards count, and it can combine with <a class="tag sub" href="#/tags/llm-assist">llm-assist</a>.
