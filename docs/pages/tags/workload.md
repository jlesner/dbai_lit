Cross-DBMS differential testing for logic bugs: each generated test case is transpiled into the dialects of Oracle, MySQL, PostgreSQL, SQLite and MariaDB, run on all of them, and any difference goes to triage, as a bug if it contradicts official documentation, else as an undocumented inconsistency (§1, PDF p. 2). <span class="links">[🔎](#/papers/oh2026queryhouse "Summary") · [PDF](https://hacking.kaist.ac.kr/pubs/2026/oh:queryhouse.pdf) · [DOI](https://doi.org/10.1007/978-3-032-38692-2_35) · [Code: QueryHouse](https://github.com/queryhouse-2037/QueryHouse) · [Code: QueryHouse-sqlglot](https://github.com/queryhouse-2037/QueryHouse-sqlglot)</span> <span class="tags"><a class="tag" href="#/tags/difftest">difftest</a><a class="tag" href="#/tags/method">method</a><a class="tag" href="#/tags/workload">workload</a><a class="tag sub" href="#/tags/dialect-translate">dialect-translate</a><a class="tag sub" href="#/tags/dsl-sql">dsl-sql</a><a class="tag sub" href="#/tags/llm-assist">llm-assist</a><a class="tag sub" href="#/tags/llm-gen">llm-gen</a></span>
