# Tag <span class="tag big">offload</span>

**Engine against text on the same task**: the item's own results compare an LLM that hands a procedure to an engine or interpreter (a program, query or formalization that is executed) with the LLM doing the same work in text or with the data in its context, or study when, or to which engine, to hand it.
