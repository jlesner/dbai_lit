- **[SPARQL 1.1 Query Language](#/papers/harris2013sparql "SPARQL 1.1 Query Language (2013)")** (W3C Recommendation 21 March 2013 (a standard, not a paper; editors Harris and Seaborne)). The W3C standard that "defines the syntax and semantics of the SPARQL query language for RDF" (abstract): graph pattern matching with optional parts, alternatives, negation, property paths, aggregates, subqueries and four query forms (§5–§16). <span class="links">[🔎](#/papers/harris2013sparql "Summary") · [Paper](http://www.w3.org/TR/2013/REC-sparql11-query-20130321/)</span> <span class="tags"><a class="tag" href="#/tags/method">method</a><a class="tag sub" href="#/tags/dsl-sparql">dsl-sparql</a><a class="tag sub" href="#/tags/nondet-semantics">nondet-semantics</a></span>
- **[Adaptive Text2GQL](https://aclanthology.org/2026.acl-long.804.pdf, "Adaptive Text2GQL: Integrating Structural Twig Linking and Evolutionary In-Context Learning (2026)")**: Integrating Structural Twig Linking and Evolutionary In-Context Learning (ACL 2026 (Volume 1: Long Papers; first-page footer, PDF p. 1)). A training-free pipeline that writes graph-database queries in Cypher, Gremlin and SPARQL from English questions: schema-filled query templates ("twigs") retrieved as hints, a few-shot example store that starts empty and grows during inference, and a correction agent that checks a query against regex rules and then runs it on the database, retrying with the error (abstract; §3–4, PDF pp. 1, 3–6). <span class="links">[🔎](#/papers/niu2026text2gql "Summary") · [PDF](https://aclanthology.org/2026.acl-long.804.pdf,) · [DOI](https://doi.org/10.18653/v1/2026.acl-long.804)</span> <span class="tags"><a class="tag" href="#/tags/harness">harness</a><a class="tag" href="#/tags/method">method</a><a class="tag" href="#/tags/nl2dsl">nl2dsl</a><a class="tag sub" href="#/tags/dsl-graph">dsl-graph</a><a class="tag sub" href="#/tags/dsl-sparql">dsl-sparql</a><a class="tag sub" href="#/tags/llm-gen">llm-gen</a><a class="tag sub" href="#/tags/promptopt-context">promptopt-context</a></span>
- **[Spider4SSC & S2CLite](https://arxiv.org/pdf/2511.09354 "Spider4SSC \& S2CLite: A text-to-multi-query-language dataset using lightweight ontology-agnostic SPARQL to Cypher parser (2025)")**: Spider4SSC \& S2CLite: A text-to-multi-query-language dataset using lightweight ontology-agnostic SPARQL to Cypher parser (preprint 2025).
