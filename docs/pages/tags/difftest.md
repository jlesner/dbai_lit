# Tag <span class="tag big">difftest</span>

**Differential testing across engines**: runs the same query, or a query and its translation, on two or more DBMSs, engine versions or configurations, and treats a difference in results as evidence of a bug or a bad translation.

<!-- filter -->

## Challenges

- **[Telling bad translations from legitimate engine differences](#/challenges/bad_translation_detection)**: When a translated query returns different results, is the translation wrong, or does no exact translation exist?
