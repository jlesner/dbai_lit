# Tag <span class="tag big">dbtask</span>

**Evaluates LLMs on database work other than writing one query from one question**: understanding SQL or predicting its results, answering questions over relational tables it is given (the LLM as the engine), debugging and repairing SQL, procedural SQL (PL/SQL), schema design, index or knob tuning, database operations, multi-turn or agentic work with writes, data pipelines; or trains a model on such a task (a learned SQL executor).
