# Tag <span class="tag big">rarelang</span>

**Languages rare in pretraining**: the item's own results measure LLMs writing programs in a language or library that is rare or absent in pretraining (low-resource, esoteric, new or private), scored by running them (tests, compiler, interpreter), or test a way to teach one (prompts, documentation, memory, weights).

<!-- filter -->

## Challenges

- **[Learning a rarely seen DSL in prompts](#/challenges/unseen_dsl_in_prompts)**: Can a compact model learn a DSL that is rare in its training data, K through the open-source ngn/k engine, from the language's documentation and its engine alone, with what it learns kept in prompts?
