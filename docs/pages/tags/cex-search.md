# Tag <span class="tag sub big">cex-search</span>

A subtag of <a class="tag" href="#/tags/cex">cex</a>

The database or input is found **without a solver or LLM**: genetic or random search, fuzzing, sampling and test-suite Distillation into compact models, or extraction from an existing database by provenance.
