- **[LRR (Localized Regex Repair)](https://arxiv.org/pdf/2510.09037 "Repairing Regex Vulnerabilities via Localization-Guided Instructions (2026)")**: Repairing Regex Vulnerabilities via Localization-Guided Instructions (EACL 2026 (Volume 1: Long Papers)). Repairs regular expressions vulnerable to ReDoS (crafted inputs that make the regex engine's matching super-linear): a symbolic module localizes the vulnerable sub-pattern, then an LLM, prompted with that sub-pattern and five chain-of-thought repair examples, rewrites the whole regex (abstract; §4; App. B). <span class="links">[🔎](#/papers/sung2025lrr "Summary") · [PDF](https://arxiv.org/pdf/2510.09037) · [arXiv](https://arxiv.org/abs/2510.09037) · [DOI](https://doi.org/10.18653/v1/2026.eacl-long.379) · [Code](https://github.com/cdltlehf/LRR)</span> <span class="tags"><a class="tag" href="#/tags/compact">compact</a><a class="tag" href="#/tags/method">method</a><a class="tag" href="#/tags/rewrite">rewrite</a><a class="tag sub" href="#/tags/dsl-regex">dsl-regex</a><a class="tag sub" href="#/tags/llm-gen">llm-gen</a></span>
- **[LARA (Lookahead Automata ReDoS Analyzer)](https://dl.acm.org/doi/pdf/10.1145/3832783.3837475 "LARA: Static ReDoS Detection for Regular Expressions with Lookahead via Matching Automata (2026)")**: LARA: Static ReDoS Detection for Regular Expressions with Lookahead via Matching Automata (ASE 2026). A static detector of ReDoS (regexes whose backtracking match time grows super-linearly with the input) for regexes with lookahead assertions: it compiles the regex into an automaton with lookahead transitions, replaces each lookahead by ε-transitions into the lookahead's own automaton (the "matching NFA"), and runs classical ambiguity analysis on the result (abstract, PDF p. 1; §3.1, PDF p. 4). The authors state the matching NFA is not language-equivalent to the regex, and prove that on every input its degree of match, a count of the (state, position) pairs backtracking visits, equals the regex's lookahead-aware count (Thm. 3.3, PDF p. 5; the proof is in supplementary material the PDF does not link). <span class="links">[🔎](#/papers/wang2026lara "Summary") · [PDF](https://dl.acm.org/doi/pdf/10.1145/3832783.3837475) · [DOI](https://doi.org/10.1145/3832783.3837475)</span> <span class="tags"><a class="tag" href="#/tags/cex">cex</a><a class="tag" href="#/tags/method">method</a><a class="tag sub" href="#/tags/dsl-regex">dsl-regex</a></span>
