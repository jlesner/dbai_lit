# Tag <span class="tag sub big">rules-discover</span>

A subtag of <a class="tag" href="#/tags/rules">rules</a>

New rules are **found**: enumerated, mined, synthesized from examples, LLM-proposed or distilled from rewrites.

## Challenges

- **[Discovering new rewrite rules](#/challenges/rewrite_rule_discovery)**: Where do new optimizer rules come from? Have an LLM propose them and a prover verify them.
