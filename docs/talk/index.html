certified

  • Show two programs differ: the document is a counterexample
  • Build an input that gives a wanted result
  • Show two programs agree, only by a decision procedure or proof
as strong as the agreement check
  • Port to another dialect
  • Minimize
  • Repair
  • Rewrite for speed
evidence only
  • Write a program from examples
  • Write a program from English, against a hidden reference program

some wrong answers pass

For LLM methods, certified checks are exact rewards; for users, only certified answers can be trusted

Why DSLs: SQL's four reasons, across the family

Precise semantics

a standard or a formal semantics; where it is prose, two engines check each other

Mature, free, offline engines

two or more per DSL; checking an answer is running them; no solver needed for most tasks

Data that matters

documents, JSON, tables, property graphs, knowledge graphs, facts, calendars, text

More ways for agents to act

agents act through a shell or Python; each reliable DSL adds a precise way into one kind of data

The bet: verdicts make programs more reliable

Do gains on checkable tasks carry over?

Like a soldier's drills: practised where every move is scored, for a fight where none can be (our analogy)

Prior work (A12): shown for RL on the weights, mostly onto tasks that are still checkable. With frozen weights: one precedent with a tuned prefix, mostly negative results for text prompts, and, in a quick sweep, no study of text prompts learned against a program checker on compact open models.

Task familyWhat checks an answerWhat a pass proves

Build an input for a wanted resultRun the program on the documentCertified, in any DSL (ours)

  • That family has 15 trials per cell
  • Its headline projection (0.42 at 8 steps) isn't (mean r)8: 0.618 ≈ 0.02

Proving agreement: a decision procedure, or a search

Regex

regular fragment

An automaton decides it: agree or differ

XPath

navigational, no counting or value tests

A static analyzer decides it; outside that fragment, search for a document

SQL

Search for a database that tells them apart; finding none doesn't prove agreement

Regex: hopcroft1971linear (deterministic automaton equivalence); stockmeyer1973word (its cost for regular expressions) · XPath: geneves2007efficient §8, Thm. 6.3 (the decision procedure), geneves2008analyzer §2 Ex. 3, Fig. 7, §3.1 (the tool) · SQL: our query-equivalence notes

Weak checks can be gamed

if doc == example_1: return "A"
if doc == example_2: return "B"
if doc == example_3: return "C"
  • A program that hard-codes the examples passes them
  • Held-out documents catch some such programs, not all (ours)
  • Text-to-SQL with no reference program: nothing checks it
